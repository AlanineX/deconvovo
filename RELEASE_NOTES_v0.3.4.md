# Waters Console v0.3.4

- Obsidian and muted sapphire dark scene; parchment and sage light scene. Native glass panels, readable title chips, local hover/focus feedback and floating menus.
- One RAW workflow: Examples, Input, Output, resizable acquisitions, Refresh, Process files and a compact CPU limit. Converted tables are reused when source data and settings match.
- Full acquired 1D samples at every zoom, aligned 2D axes, editable numeric ranges, target drift extraction and current-view PNG/CSV exports. Portable HTML is a separate fully offline export.
- Calibration plots above the editable reference table; Highest, Last and manual numbered peaks, bulk selection, cached fitting, reusable curves and explicit Generate CCS. Linked target CCS profiles occupy the right column.
- Seven complete real acquisitions retain all 106 original files. Friendly demo names, short README and linked CSV/math guides.

Extract the complete Windows ZIP and run `WatersConsole.exe`. Extract the Linux archive and run `WatersConsole`; RAW conversion additionally requires Wine. The Linux binary targets Ubuntu 24.04 x64 or a compatible system with glibc 2.39 or newer. Both viewers work offline and contain no Chromium.

The bundled protein-to-ADP example demonstrates the workflow: its fit requires review, many target results extrapolate, and acquisition conditions differ. It is not a quantitative validation standard. Betaine's 1000–2000 m/z detail contains unassigned high-mass features.

The published application archives are the exact candidates exercised with the real acquisitions on Windows and Linux. SHA-256 checksums, build provenance, validation reports and native GUI PNGs accompany them.
